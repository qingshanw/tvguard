# 题库格式说明

## Excel 模板(推荐给家长)

用 Excel/WPS 打开 `题库模板.xlsx`,列固定为:

| 题目 | 选项A | 选项B | 选项C | 选项D | 答案 |
|------|-------|-------|-------|-------|------|
| 地球围绕什么转? | 太阳 | 月亮 | 火星 | 金星 | A |

- 表头第一行不要修改;
- "答案"列填 **A / B / C / D**(对应正确选项);
- 选项最少 2 个,最多 4 个(不够的列留空即可);
- 填好后用浏览器打开 `转换器.html` 转成 `questions.json`。

## JSON 格式(电视端统一格式)

```json
{
  "version": 1,
  "questions": [
    {
      "q": "地球围绕什么转?",
      "options": ["太阳", "月亮", "火星", "金星"],
      "answer": 0
    }
  ]
}
```

- 文件必须为 **UTF-8 编码**;
- `answer` 为正确选项的下标,**从 0 开始**(0=第1个选项,1=第2个……);
- `options` 至少 2 项;
- 一份文件里题目数量不限。

## 导入电视的两种方式

1. **U盘/本地导入**:把 `questions.json` 拷入U盘 → 电视上打开 App → 题库管理(或家长设置页)→ "从U盘导入" → 选中文件。
2. **局域网上传**:家长设置页打开"局域网上传题库" → 电视上会显示类似 `http://192.168.1.100:8765` 的地址 → 手机浏览器访问该地址 → 选择文件上传,电视上提示"导入成功"即生效。

## 注意

- 多次导入会生成多个题库文件,全部生效、随机出题;可在"题库管理"里删除不需要的;
- 格式不合法的题目(缺题目、少于2个选项、答案越界)会在导入时报错指出第几行,不会导入;
- App 自带一个 20 题的内置常识题库,未导入自定义题库时也能正常使用。
